# 化学请求与电荷模型适用性验证

## 背景
2025 年 AutoSolvate Web 化学适用范围有限。

## 任务
筛查所有请求并实现路由：报告首个失败条件或所用电荷模型。

## 要求
依据元素计数、电荷、多重度、连通组分、碘键合度，不依名称/ID。电子数=Σ(原子序数×计数)−电荷；有效多重度为正整数≤电子数+1且电子数−(多重度−1)为偶数。按序检查电子态、元素 H/C/N/O/P/S/F/Cl/Br/I、恰好一个组分、碘键合度为空或≤1。仅报首个失败，不启动拒绝请求。通过的单重态用AM1-BCC，开壳层用RESP。每请求一项，保留电荷/自旋；数量为有限整数值。读取 requests.json，在 /app/final/ 写 decisions.json、可运行 route.py、analysis.md。公开输出约定定义字段/原因。本题无需量化计算。

## 文件

公开输入文件：

| 文件路径 | 说明 |
| --- | --- |
| `/app/inputs/` | 待审计的请求。 |
| `/app/output-contract.yaml` | 输出格式与证据要求。 |

/app/inputs/：请求；/app/output-contract.yaml：格式；/app/final/：决策和代码。
