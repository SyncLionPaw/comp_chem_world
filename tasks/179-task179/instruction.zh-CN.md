# 任务：生成孤立水分子

## 背景

生成一个电中性、近似平衡几何的孤立 H₂O 分子。本题只需 Python 3.12 标准库，不要求 DFT 或模拟。

输入与可用资源按下文说明；需要自行获取的资料仍由任务执行者获取。

## 任务

提交分子几何及可重复生成该几何的小脚本。

## 要求

- 环境：使用容器 `PATH` 上的 Python；所需科学计算包已预装。不要自行安装额外软件包，也不要通过网络获取依赖。

几何须恰含一个 O 和两个 H，使用有限的笛卡尔坐标，单位为 Å。每个 O–H 距离须在可信平衡参考值的 0.060 Å 范围内，H–O–H 角须在 6.0° 范围内。坐标系和 H 原子顺序不限。生成器须重现所提交的几何，键长容差为 1e-6 Å，键角容差为 1e-6°。

### 输入与产物细则

- final/water.xyz：标准 XYZ，含原子数、注释行和三行原子数据。
- final/generate_water.py：自包含 Python 脚本；从任意工作目录运行 python generate_water.py，须在当前目录写出 water.xyz。仅使用标准库。
