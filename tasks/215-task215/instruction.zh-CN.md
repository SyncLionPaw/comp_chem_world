# 活性位点配位几何、Asp181 旋转异构体与 WPD 环状态

## 背景

从十个沉积晶体结构计算活性位点配位、Asp181 旋转异构体和 WPD 环状态。

输入包括晶体结构。

## 任务

从十个沉积晶体结构计算活性位点配位、Asp181 旋转异构体和 WPD 环状态。

## 要求

- 覆盖恰好十个沉积结构。
- 按坐标识别 VO4、WO4 或无配体；无配体字段使用 null。
- 按催化基序定位 Cys215，按 WPD 定位 Asp181。
- 中心原子到 SG 及全部四个配体氧的距离以 Å 至少保留两位小数。
- Asp181 N–CA–CB–CG χ1 范围为(−180°,180°]，|χ1|≥120°为 productive；Asp181 CA–Cys215 CA ≤10.0 Å为闭环。
- 替代构象取最高占有率，同值按标签排序（空白/A优先于B）。
- 科研数据仅使用已提供的输入。

- 提交的 JSON 对象成员名必须唯一，数值必须有限；产物路径可指向 `/app` 内的文件。
- 每个配体氧的距离均从中心 V/W 原子测量；ligand_sg_distance 为中心 V/W 至 Cys SG 的距离。
- 按所列输出约定提交规定产物。
