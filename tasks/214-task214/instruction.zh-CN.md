# 磷酸半胱氨酸中间体体系准备

## 背景

建立质子化状态符合水解机理的 PTP1B 共价 CSP 中间体溶剂化模型。

输入包括晶体结构、CSP 力场参数和起始重原子坐标。

## 任务

建立质子化状态符合水解机理的 PTP1B 共价 CSP 中间体溶剂化模型。

## 要求

- 使用给定 CSP 模板、frcmod 和 Amber 蛋白力场。
- 明确全部可滴定状态及 HID/HIE/HIP；磷酸最近的催化 Asp 必须为 ASP。
- 无冲突时保留晶体水。
- 采用周期八面体 TIP3P，盒面间距≥10 Å，以 Na+/Cl− 中和至 0.000 ±0.001 e。
- 恰好一个共价 S–P CSP；重原子间距不得小于0.8 Å；拓扑坐标原子数一致且可由 LEaP/CPPTRAJ 读取。
- 按拓扑一基索引审计全部可滴定残基；沉积编号比标准编号小1。
- 科研数据仅使用已提供的输入。

- 提交的 JSON 对象成员名必须唯一，数值必须有限；产物路径可指向 `/app` 内的文件。
- 按所列输出约定提交规定产物。

## 文件

| 路径 | 说明 |
| --- | --- |
| `/app/inputs/` | 结构、计算记录与参考数据。 |
| `/app/inputs/output-contract.json` | 输出内容与提交格式。 |
| `/app/` | 提交结果与必要运行证据。 |
