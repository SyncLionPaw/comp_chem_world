# MM-GBSA 关联、排名与失败归因

## 背景

MM-GBSA 用于估计结合能，本题将其与 OpenBPMD 姿态评分进行配对比较。SI 能量数据覆盖40体系200姿态；两个 DPP4 体系因来源计算失败而缺少能量结果，不补值，也不使用不同分母比较。

Table S1 提供 42 个体系的姿态标识、RMSD 和 OpenBPMD 评分。SI 能量数据覆盖 40 个体系的 200 个姿态，来源文件记录数据出处和排除原因。

## 任务

按 pose_id 匹配来源数据，计算 MM-GBSA 与姿态 RMSD 的关联及与 OpenBPMD 的重排序性能。分析溶剂、熵和有限采样解释，构造能保持观察结果但具有不同主导误差的反模型，并提出可区分解释的配对控制。区分观察、假说与因果结论。

## 要求

- 使用相同的 200 姿态、40 体系分母比较。验证 `pose_rmsd_A` 与来源一致。按实际变量方向解释相关系数，不预设符号或通用阈值。体系内姿态相关，合并 p 值仅为名义值，不作独立同分布或因果证据。短轨迹不单独证明采样不足，姿态逃逸不等于结合自由能或热力学平衡。
- 报告讨论溶剂表示、构象熵、动力学滞留与偏置扰动的支持证据、反证及未测量量。控制应分别在固定姿态/力场/采样下改变溶剂，在固定轨迹/溶剂下改变熵估计，在固定哈密顿量/估计器下增加独立采样。反模型的潜在能量不是实测亲和力、能量分解或已证实的修正方法。
- 反模型容差为 max(1e-7,1e-7*abs(expected))；聚类统计容差为 max(1e-8,1e-7*abs(expected))。JSON 数值必须有限，布尔值不作为数值。x 为 MM-GBSA binding energy dG (kJ/mol)，亦接受 kJ mol^-1 或 kJ mol⁻¹；y 为 pose RMSD (Angstrom) 或 pose RMSD (Å)，n=200。kcal/mol 与 nm 不是同单位别名。`excluded_systems` 为唯一 ID 集合；并列成功率区间含有限 min/max 与整数 n。

输入索引、输出字段、单位和数值协议见文件部分所列的输出协议。所有运行证据保存在`/app/` 交付目录内。

提交的 JSON 对象成员名必须唯一，数值必须有限；产物路径可指向 `/app` 内的文件。
