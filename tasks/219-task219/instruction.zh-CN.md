# 多尺度机理综合与失活诊断

## 背景

给定的化学能垒、环动力学、序列与静电证据涉及周转变化及 Chimera 1 失活。

给定数据集包含动力学、EVB、序列及 MSM 证据。

## 任务

比较化学能垒、环动力学、序列与静电证据，评估周转变化及 Chimera 1 失活的可辨识性。

## 要求

- 定量比较 WT 与 Chimera 7/4/3，保留六残基有符号静电比较及独立基序计数。
- Chimera 1 三项缺失 MSM 量及实验活化能垒使用来源绑定 null。
- 提交来源量、派生运算、报告、归因矩阵和构造性机理证书。
- 每体系构造两个相反串联等待分配（化学比例≤0.1与≥0.9）、两个 C1 零周转边界模型及观测等价 E-loop 模型。
- 不得将 MSM 开环等同有效到达、残余能垒等同门控或反事实模型等同实测干预。
- R=0.00198720425864083 kcal mol⁻¹ K⁻¹，T=298.15 K，容差max(1e-6,1e-6*abs(expected))。
- 保留条件前因子不确定性及有证据的候选机理、反证和区分测量。
- 科研数据仅使用已提供的输入。

- 归因矩阵中的来源路径从数据集 JSON 根节点开始，以斜杠分隔键，不加文件名前缀或开头斜杠；例如 `kinetics_25C/WT_PTP1B/kcat_s_inv`。
- 提交的 JSON 对象成员名必须唯一，数值必须有限；产物路径可指向 `/app` 内的文件。
- E-loop 反事实模型的求和只包含 K120_E_loop、E115_E_loop、K116_E_loop 和 R112_E_loop；归因矩阵仍须分别报告全部六个残基。
- 派生量的 `operation` 须直接填写输出契约中的枚举值，如 `ratio`、`difference` 或 `eyring_rate_ratio`，解释文字放入规定的理由字段，不拼接在枚举值中。四残基 E-loop 求和保留正负号，不取绝对值，也不加入 N111 和 L110。
- 按所列输出约定提交规定产物。
