# 原生计算、预测与执行记录的证据审计

## 背景

本题利用给定的 CP2K 记录、归档预测、选定帧和公开事件账本的字段投影开展回顾性审计。投影不等于完整源账本。原生结果有效性、引擎退出、进程完成和调度器状态须分别判断；缺少调度器终态记录应记为未知。不得运行 CP2K、MD、训练或网络服务，也不得声称前瞻性合规或整个候选池的精度。

## 任务

重建输入和尝试记录的证据，比较指定参考对，量化选定帧的力误差，核对两种预算视图，并判断证据是否足以支持参考充分性。提交 `audit.json` 和简洁、关联证据的 `decision.md`。

## 要求

- 环境：使用容器 `PATH` 上的 Python。已预装 NumPy。不要自行安装额外软件包，也不要通过网络获取依赖。

- 根据 `inputs/public-input-manifest.json` 核验全部输入。区分原始意图集合 `L01`–`L20` 与回顾集合 `L02`–`L20` 加 `D1`。将每次尝试关联至输入、有序几何、选定帧、原生有效性、引擎退出、进程状态和调度器证据。分别记录这些状态；缺失的调度器终态证据记为未知。
- 严格按顺序比较 `D1/L01`、`D1/R01` 和 `B01/S01`。解析方法、泛函、色散／参考、截断、SCF 设置、晶胞向量、周期性和几何同一性。按输出约定的换算和阈值报告每原子绝对能量差、笛卡尔力分量 RMSE、最大原子力向量差；阈值分别为 `1e-4 eV/atom`、`0.01 eV/Å` 和 `0.05 eV/Å`。仅当两份原生记录和进程均通过核验且设置存在差异时，该对才具备比较资格。
- 对全部 20 个选定帧，报告四个模型及其算术平均集成的力分量 RMSE 和最大原子力向量误差，关联选择项／帧／温度／轨迹／类别及证据。对各总体，报告四个温度／轨迹层内的随机选择和风险选择结果（八个单元），包含全部选定项。 各层误差汇总仅使用原生有效且进程成功已核实的记录；缺失率界限的分母仍包含全部选定记录。仅在原生和进程证据均经核验且集成 RMSE ≥0.15 eV/Å 时计为命中；对于 `n` 个选定项、`h` 个已核验命中及 `m` 个缺少已核验进程证据的选定项，报告 `[h/n,(h+m)/n]`，并按输出约定，在一致标明的同一总体及同一轨迹内比较随机／风险选择。
- 在选定的 `L01` 帧上，将 `D1`、`R01` 分别与集成预测比较，报告误差和命中变化，但保持归档的基于模型分歧的风险排序不变。不得推断整个候选池的精度或独立采样。
- 在不同记账轴上核对原始的 28 次量子标注意图上限与后续的 54 次操作者尝试上限，包括开始、完成、退出、恢复、操作者事件、启动前失败及计费／未知作业。说明账本只是字段投影。
- 审计结构和数值规则遵循 `inputs/output-contract.json`。在 `audit.json` 中提出三个不同且有排序的下一步取证行动，各自包含缺口、理由、停止条件、证据依据及一个预算轴（`analysis_only`、`existing_evidence_only` 或 `separate_authorization_required`）。`decision.md` 可采用任何清晰的文字形式，但科学优先级须与审计一致。
- 不得声称前瞻性预算合规、生产级或整个候选池的精度，也不得声称独立采样。
