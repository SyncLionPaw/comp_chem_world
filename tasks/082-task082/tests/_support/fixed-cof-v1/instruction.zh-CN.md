# 任务：使用 ADMM-PBE0 和 sTDA 筛选 COF 激发态

## 背景

所提供的论文和补充信息介绍了 COF 05001N2（CURATED COFs 标识 05001N2）的周期模型、电子结构方法、光谱计算和已发表比较。文件位于 `/app/inputs/`。

## 任务

验证公开结构是否符合 SI Table 52 和论文 Table 4 的描述。使用 ADMM-PBE0/ccGRB-T+tzp 优化固定周期晶胞。在该基态几何上，分别使用完整 ADMM-PBE0 和 sTDA@ADMM-PBE0 计算最低 500 个单重激发态及振子强度，并采用可复现且有来源支持展宽参数的光谱处理方法。对每种响应核使用八态流形优化 S1 几何，并验证态的连续性。将两种方法的垂直激发能、电子绝热激发能、荧光能和 Stokes 位移与论文 Table 5 中 05001N2 单体系数据比较。查看两种方法的差值之前，先确定有独立依据的准确度阈值和数值误差预算。

## 要求

1. 确认检索到的结构并与 SI Table 52 和论文 Table 4 对照。报告晶胞、组成、原子数和基函数数、检索来源、坐标或对称性处理、来源页码及数据提取方法。保留固定晶胞基态优化、两套 500 态计算和两套八态 S1 优化的输入、完整 CP2K 原生日志、最终几何及收敛证据。提供两次激发态优化过程中的态序和跃迁特征以证明态连续性，并说明可复现的光谱处理方法、来源支持的展宽、收敛检查、运行时间和成本构成。
2. 将两种方法的垂直激发能、电子绝热激发能、荧光能和 Stokes 位移与 Table 5 单体系数据并列报告，注明定义和引文。使用 `Ead = E0(R_ES) + ω1(R_ES) − E0(R_GS)`；CP2K 在优化后激发态几何处给出的总能已包含 S1 能量，不得重复加上激发能。区分电子能与振动 0–0 能。仅在有同一模型下可靠零点能修正时报告 0–0 值；否则标为不可得，并说明论文约定尚未解决之处。
3. 在比较响应核之前说明准确度阈值、独立依据和数值误差预算；不得从多 COF 平均误差推断单体系阈值，也不得在看到结果后放宽阈值。量化敏感性、不确定性及相对阈值的余量，并计入发表数值舍入和单位换算。检查能量差、Stokes 恒等关系、态连续性、光谱形状、数值收敛和计算成本。根据证据作出筛选判断并说明局限；不得拟合已发表数值或在证据不足时声称复现。
4. 科学结论须基于完整的原生执行证据及独立科学复核。仅报告使用获准计算资源实际完成的计算。明确说明缺失证据和未解决的不确定性，不得将不完整运行表述为已完成的科学结果。

## 文件

将研究记录放在 `/app/final/`：

- `geometries/`：基态和两种激发态几何、对应输入及完整 CP2K 原生日志；
- `spectra/`：两种方法各自的 500 态能量和振子强度，以及处理代码或参数；
- `table5.csv`：两种方法的四项能量及论文单体系数据，并注明定义；
- `report.md`：筛选判断、文献比较、数值与成本分析、不确定性和未解决问题；
- `provenance.json`：结构检索、输入、输出、参数及报告数值的追踪信息。

[公开输出格式说明](/app/inputs/case07-output-contract-v1.schema.json)定义提交字段和 `table5.csv` 列。该文件说明记录格式，不代表科学认可。
