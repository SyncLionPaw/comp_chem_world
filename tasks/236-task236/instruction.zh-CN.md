# 偶极自关联介电响应与双振子拟合

## 背景

极性材料的介电响应可由分子动力学轨迹中总偶极矩的自关联估计。然而，单条有限轨迹且频率 bin 彼此相关时，只支持描述性拟合，而不支持唯一模态指认或无条件绝对介电常数。给定记录是 6×6×6 超胞的偶极与晶胞体积时间序列，其单位必须显式处理。

输入包括逐帧的超胞总偶极矩及对应瞬时晶胞体积，以及各单位假设下的条件静态介电值。

## 任务

完成规定的汇总结果：静态估计、自关联/ESS、谱、单/双振子拟合与 2/4/6 ps 窗敏感性。

在 [0.3, 0.7] 内选择 `split_fraction`，在 [2, 8] 内选择两个相差至少 1 ps 的 `lag_windows_ps`，并记为 `spec`。按公开的 `autonomous_controls.py` 规则计算 `results`：在前段连续块上训练，用训练得到的振子参数与归一化留出谱预测后段连续块，不对留出块重拟合。

## 要求

- 固定评价集始终包含 2、4、6 ps 以及所有自选窗；全部频率 bin 与全部固定窗均为必需。任何自选的成功窗都不能掩盖不利的固定控制。
- 报告每个训练拟合、单/双模型的完整留出残差向量与 RSS，以及双模型是否改善全部留出比较。有效的负面结果也应如实报告。
- 对现有完整序列的拟合仍为必需；留出分析是增加证据，而非替代。
- 单条有限记录且频率 bin 相关时，无法识别统计模态必要性或无条件绝对介电常数。保持 `static_dielectric_constant=null`、eBohr/eAngstrom 条件响应、`single_oscillator_sufficient` 与 `two_oscillator_statistically_necessary` 均为 null，且拟合状态须符合公开契约的描述性限制。`scope` 必须与完整残差证据同时给出。
- 使用解析振子雅可比，并在公布的初值、边界与评估上限下设置 `ftol=xtol=gtol=1e-13` 与 `x_scale="jac"`。这些是优化停止规则；输出比较容差与拟合统计量的描述性限制不变。
- 规范算术与序列化容差见所列输出约定。

可用以下命令复现规定的结果：

```
python3 /app/public/replay.py /app/final
```
