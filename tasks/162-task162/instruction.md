# Task: Audit the XAlkeneDB reference database, electronic-state conventions, and training inputs

## Background

The task uses the equivariant message-passing network SPaiNN to fit excited-state properties and drive nonadiabatic dynamics. Correctly understanding the public reference database XAlkeneDB (Zenodo 10736050) is a prerequisite for its training and analysis. The supplied databases contain Wigner-sampled reference data computed at SA(3)-CASSCF(2,2)/cc-pVDZ.

## Task

Audit the formats and properties of the three Wigner-sampled databases, and verify the consistency constraints contained in the databases. Determine the data dictionary semantics, including key names, array shapes, and coupling-axis order, from the data and provide evidence, for example by cross-validating mathematical relationships among different properties.

Use the minimum S0 energy of each molecule as its common relative-energy reference. Use the population standard deviation (`ddof=0`) and report the mean, standard deviation, and extrema, covering every row required by the output contract.

## Requirements

- Environment: use the container Python on `PATH`. Preinstalled packages include ASE, matplotlib, NumPy, pillow, SciPy. Do not install additional packages or fetch dependencies from the network.

The databases were generated by a SHARC pipeline, so coordinate and property units differ from ASE's default conventions. Infer and state the units and conversions using physical constraints in the data, such as bond lengths and energy scales.

State the units, evidence chain, and any uncertainty in your conclusions. Do not assert anything that the data cannot support. For each molecule and coupling, report `n_points` as the total number of scalar coupling components checked across all records and atoms, counting all three Cartesian components for each atom (equivalently, sum `n_atoms × 3` over records).

### Input and deliverable details

- `inputs/databases/01_3Sing_C2H4.db`, `02_3Sing_C3H6.db`, and `03_3Sing_C4H8.db`: ASE SQLite databases readable with `ase.db.connect`; each row's `row.data` dictionary contains multistate properties. The molecules are ethylene (6 atoms), propylene (9 atoms), and butylene (12 atoms).
- `inputs/README.md`: background information about these inputs.
- `inputs/output-contract.md`: required deliverables: four files under `outputs/`.
