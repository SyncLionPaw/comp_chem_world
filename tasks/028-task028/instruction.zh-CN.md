# 任务：Holy Grail：研究芳烃 BPR 重排对气溶胶形成的作用

## 背景

双环过氧自由基（BPR）重排被提出为芳烃氧化中维持自氧化、并通向富氧气溶胶前体的一条路径。请通过独立计算研究判断现有证据能在何种条件和范围内支持这一主张。本任务是开放研究问题：不提供科学输入、计算方法、分子范围、指定路线或参考解。所需输入须由你自行获取或构建，并对科学决策作出说明。

## 任务

设计并执行计算研究，用新的、可追溯证据检验核心主张。给出明确结论、覆盖的体系和条件、定量依据、与实际近似相对应的不确定度、局限，以及可能改变结论的证据。只有在条件和参考物种群体有意义地匹配时才比较速率。解释计算如何支持或不能支持“重排通向气溶胶前体”这一联系。不得仅凭分子速率夸大对气溶胶形成或产率的证明。

区分新计算、获取的数据和外部数值。对失败、部分完成和缺乏支持的工作如实报告。复用计算的结论须限于原有条件和范围；不得将其计为新执行的工作，也不得在缺少依据时声称已经收敛。

## 要求

- 环境：使用容器 `PATH` 上的 Python；所需科学计算包已预装。不要自行安装额外软件包，也不要通过网络获取依赖。

使用 HPC 时，按 `ikkem-slurm` 的统一流程执行：探测已授权的目标，提交作业，等待终态，回收原生输出，再核验科学结果。

整个尝试期限为 8 小时，包含排队等待。失败和取消的分配也计入尝试记录。记录已提交、失败、取消及完成的作业并报告实际资源用量。若 SSH/Slurm 接入不可用或证据缺失，应如实说明，不得编造作业记录。保护 SSH 凭据，不得写入输出或日志。科学结论须有独立证据支持，不能仅凭提交格式正确或文件齐全确立。

使用 HPC 完成计算。保留原生计算文件、作业记录和实际资源用量。遵守集群当前提交策略，并区分请求资源与实测用量。

### 输入与产物细则

提供 `final/claim.md`、`final/native_evidence/` 和 `final/provenance.json`。结论须将每项定量主张与不确定度和证据相连。保存原生输入与输出、获取的来源、作业记录和分析文件。来源与证据须在 `provenance.json` 中按公开完整 schema 记录，包括路径和哈希、来源归属、执行关联，以及速率比较所需的条件和参考物种群体。具体格式见容器内的公开合同 `/app/output-contract.json`。现有 `ikkem-slurm` 接口及原生记录要求见 `/app/research-service.md`，配置位于 `/app/submit-job.json`。

从 `/app` 使用现有 `ikkem-slurm` 客户端操作 Slurm，并将所有 `.submit-job/*.json` 状态文件原样保存在 `final/native_evidence/slurm/`，包括失败和取消的作业。保留原始计算文件，并将科研阶段与对应作业 ID 关联。
