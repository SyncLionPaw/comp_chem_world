# Task: Infer the two-mode dielectric kernel from five response targets

## Background

The public input `/app/assets/response_targets.json` gives five synthetic observables generated from the fixed two-mode kernel. The kernel form is fixed:

`eps(k) = 1 + 1/(K21 + K22 k^2) + 1/(K11 + K12 k^2 + K13 k^4)`, `chi(k) = 1 - 1/eps(k)`,

with `k` in Å⁻¹, `K11`/`K21` dimensionless, `K12`/`K22` in Å², `K13` in Å⁴, and `K12` negative.


## Task

Infer the five coefficients from the targets. Choose and justify an inversion method, initial values, and restart strategy, and check whether another parameter branch also fits the same targets.

## Requirements

- Environment: use the container Python on `PATH`. Preinstalled packages include matplotlib, MDAnalysis, NumPy, pillow, SciPy. Do not install additional packages or fetch dependencies from the network.

- Respect the DKM rule: for real `k >= 0`, finite `eps(k)` must not lie in `0 <= eps(k) < 1`. Near a pole of `A(k)=K11+K12 k²+K13 k⁴`, `eps` may become very large and negative; that alone is not a violation. Check finite values between poles, not just the minimum of `eps`.
- Each reply's residual vector is ordered `[eps_w, k_min, chi_min, k_max, delta_k]` and equals `(features - targets) / [1, 0.02, 0.01, 0.02, 0.02]`. Compute `chi(k)` on 200001 evenly spaced points from 0 to 8 Å⁻¹; choose the smallest-k local minimum and the greatest-chi maximum, refine each extremum with a three-point quadratic, and linearly interpolate `chi` at the refined location. Find the half-maximum crossings inside `k_max ± 3 Å⁻¹`, linearly interpolate them, and use the first and last crossing for `delta_k`.
- For this container, read `/app/assets/response_targets.json` and write outputs under `/app/final/`. Run `python solver.py /app` for fitting. When objective-callback responses are supplied through `python solver.py /app --objective-rpc`, the same source must support deterministic replay.
- In objective-service replay mode, reserve stdout for JSON Lines queries such as `{"type":"objective_query","seq":0,"K":[K11,K12,K13,K21,K22]}` and read each corresponding stdin response, such as `{"type":"objective_result","seq":0,"residual":[r1,r2,r3,r4,r5]}`. Send diagnostics to stderr. The public `/app/assets/objective_features.py` defines the feature map and scaled residual. Finite coefficients with an invalid sign pattern return five `10.0` residuals; non-finite coefficients are invalid JSONL inputs and are rejected. Query the final coefficient vector at least once; the replay must reproduce `kernel_params.json` and `response_curves.csv` byte for byte.
- Make the replay deterministic: fix any random seeds and use stable numeric output formatting so the replayed parameter and curve files are byte-for-byte identical to your submitted files.
- Objective-service replay limits are 175 seconds wall time, 10000 objective requests, a 2 MB source, 5 MB per output file, and 64 KiB per JSONL request.

A supported coefficient set must reproduce all five target observables within 0.02, 0.002 Å⁻¹, 0.001, 0.005 Å⁻¹, and 0.01 Å⁻¹ for `eps_w`, `k_min`, `chi_min`, `k_max`, and `delta_k`, respectively. The DKM band must satisfy its rule analytically over the nonnegative real axis, and the curve must agree numerically with the coefficients.

Curve comparisons use relative tolerance 3e-6 and absolute tolerance 2e-8 in the declared units.
