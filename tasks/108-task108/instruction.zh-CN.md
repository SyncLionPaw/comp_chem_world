# 实现硅裂纹的柔性边界模型

## 背景

Sinclair 柔性边界模型将原子裂纹核心与各向异性 Mode-I 弹性场耦合。区域划分、混合能量、裂尖闭合和多子晶格 Cauchy–Born 修正项必须描述同一力学体系。模型方程见 `/app/spec.md`。

## 任务

使用 Stillinger–Weber 硅势实现该模型，求以 `K/K_G` 表示的晶格陷获区间 `[K₋, K₊]`。两个极限须是指定键中心晶格位点上，同一连通力平衡分支的上下折叠点。低于 `K₋` 时裂纹后退一个晶格周期并愈合，高于 `K₊` 时前进一个周期。区间须包住 Griffith 载荷，并在等价的类体相裂尖位点间可复现。

## 要求

自行实现区域构造、柔性边界耦合、混合能量、裂尖广义力、内部位移修正项及其导数。原子能量与力使用 SW 势。不得导入、移植或转写 `matscipy.fracture_mechanics`、`matscipy.cauchy_born` 或相关裂纹驱动代码，也不得复用本题专用的已发表或在线解答。其他获准工具见 `/app/spec.md`。

采用规定的键中心裂尖配准，并提供可独立核验一致性的构型。弛豫弹性常数 `C11/C12/C44` 和 `K_G` 与参考相差须不超过 3%。用能量有限差分验证原子力，相对误差不超过 0.5%；连续体残余力不超过 5×10⁻³ eV/Å。最低和最高载荷处，裂尖闭合及修正项导数与有限差分的相对差异不超过 6%。内部位移修正项在给定留出应变上的相对误差不超过 5%，对称禁戒应变响应为零。每个陷获极限在 `K/K_G` 上的绝对误差不超过 0.04。具体定义和参考条件见 `/app/spec.md`。

在正确一侧以载荷宽度 ≤0.02 夹逼每个折叠点，报告其中点，并用构型确认一个晶格周期的愈合或前进。钝化、重构、键软化或数值未收敛均不足以确认折叠点。

**交付物**

在 `/app/out/` 提交 JSON 或 NPZ 数据，涵盖弹性与解理性质、力、裂尖闭合、内部位移和两个折叠点的夹逼证据，并附复现检查所需的构型。

遵循 `/app/spec.md` 中已有的数据约定。弹性常数使用 GPa，`K_G` 使用 GPa√Å，陷获载荷使用 `K/K_G`；明确声明的等价单位按该规范处理。时间预算为 28,800 秒。
