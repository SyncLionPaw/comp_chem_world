# 缺陷团簇

## 背景

大型级联构型的残留缺陷和团簇需要与配准及周期映射伪影区分。

所供初态与末态各含1600万原子，分别用于构建周期参考和映射缺陷；`request.json` 规定科学范围、单位和控制要求。

## 任务

对作者 16 million atom 等原子比 MoTaVW 的辐照初态与140 ps末态，重建 Wigner–Seitz 参考，统计残留空位/间隙及团簇；仅分析已有构型，不运行100 keV级联，也不由单次末态推断普遍抗辐照优越性。 团簇统一在参考WS位点中心上建图：空位权重1，过占位点权重occupancy−1，团簇size为节点权重之和；此约定不等同于选择某一颗dumbbell原子作为唯一间隙位置。

## 要求

- 使用 `hpc` 检查已配置集群，并在Slurm分配的计算节点上执行完整构型解析与参考重建、全量Wigner–Seitz映射和配准变体、聚类及规定对照。本地仅用于准备、传输、监控、轻量检查及最终产物整理；连接或调度失败后不得以本地生产计算替代规定的集群计算。
- 集群探测须遵守已配置的连接等待设置。连接或调度无法恢复时，保留失败证据并报告执行受阻；不得伪造成功，也不得将启动后取消的生产作业记为完整计算。
- 保留提交脚本、科学命令与输入身份、作业ID、原始调度回执、计算节点原生日志，以及作业与最终产物的对应关系。执行记录收集至 `/logs/agent/hpc-evidence/`，科学产物仍回收到原规定路径；调度正常退出本身不证明科学结果正确。
- 分析完整的两份1600万原子 MoTaVW 构型，即初态和所给100 keV级联的140 ps末态。从初态构建完整周期参考并映射所有末态原子；不运行新级联，也不以单次末态推断普遍抗辐照优越性。
- 保持精确占据守恒、参考位点身份和完整原子到位点映射。在参考位点中心按指定2NN约定聚类空位、按3NN约定聚类间隙；空位权重为1，间隙权重为occupancy−1，团簇大小为权重之和。这不等同于选定唯一dumbbell原子作为间隙位置。
- 至少计算两种完整映射的配准平移和每种缺陷的两个截断变体，保留已知缺陷、周期边界、平移、化学重标记、配准和截断对照。跨周期边界的团簇只计一次，并声明周期质心约定。
- 自主选择空间索引和实现方式，保留 所列输出约定。保留解析、配准、映射、聚类代码、输入、原生输出和失败或中止的尝试。不要求 MD 执行日志。未提供参考答案。

- 按所列输出约定 将所需结果和证据提交至 `/app/results/`。 在 `metadata.json` 中声明缺陷元素和 ID 约定，并保留多占位点的额外原子与映射索引。
