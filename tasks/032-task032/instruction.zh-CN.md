# 从真实轨迹构建分子接触网络

## 背景

给定的 11 帧示例轨迹包含 1,728 个分子：N130 五聚体和 rpL5 肽。供给的 `selections.json` 给出 A0/A1/A2 的酸性珠子类型和 rpL5 的碱性珠子类型。短轨迹只采样一个局部区域，帧之间相关，不能建立系综级双峰性或渗流。

## 任务

为每个酸性区段（A0/A1/A2）与 rpL5 构建无权、无向的分子级接触网络。从供给平均 RDF 的第一局部极小导出每个接触截断，并将其与给定的历史操作截断区分；报告物种特异和总体度分布，包括孤立分子。

## 要求

- 环境：使用容器 `PATH` 上的 Python。已预装 matplotlib、MDAnalysis、NumPy、pillow、SciPy。不要自行安装额外软件包，也不要通过网络获取依赖。

使用周期性最小镜像距离和 DCD 帧盒，严格 \(d<\text{cutoff}\)。用 `selections.json` 中的类型列表（`N130_acidic_types`、`rpL5_basic_types`）把珠子映射到分子，每个分子对只计一次，去除自环，保留所有分子（包括零度节点）。原始历史截断为 A0 = 13.0、A1 = 13.0、A2 = 12.5 Å；独立导出数据极小。在 A0 [12.75,14.0]、A1 [12.5,13.25]、A2 [12.0,12.75] Å 内选择截断，论证选择，并检验一个 bin（0.5 Å）扰动下的敏感性。敏感性不是统计不确定性。结论限于 11 个相关帧支持的范围内。

## 文件

公开输入文件：

| 文件路径 | 说明 |
| --- | --- |
| `/app/environment/assets/` | 模拟配置、选择定义、轨迹与径向分布数据。 |

输入位于 `/app/environment/assets/`（`rpL5_init.data`、`selections.json`、`rpL5_example_traj.dcd`、`RDFs_rpL5_charged_A{0,1,2}Pep.txt`）。把结果写入 `/app/final/`：

- `graphs.npz`：恰好 `A0`、`A1`、`A2`；每个为 `uint8` 邻接数组，形状 `[11,1728,1728]`，按 DCD 帧序和排序后的 LAMMPS 残基/分子 ID 顺序，对称、对角为零，保留孤立节点。
- `degrees.npz`：恰好 `A0`、`A1`、`A2`；形状 `[11,1728]` 的整数数组，等于邻接行和。
- `cutoffs.json`：恰好 `A0`、`A1`、`A2`；每个为有限截断（Å），且等于该图实际使用的值。
- `report.md`：珠子到分子映射、距离和接触定义、RDF 极小导出、截断理由、敏感性、含孤立节点的物种特异和总体度分布，以及短轨迹限制。
- `analysis.py`：确定性、可复现的分析。必须接受 `--input-dir` 和 `--output-dir`，从输入目录读取六个公开输入文件，写出其余输出，并使用上述接触约定。

避免 NaN/Infinity，`/app/final/` 中只放这五个文件。

`analysis.py` 必须在容器自带的 Python 下、仅使用其预装包（NumPy、SciPy、matplotlib、MDAnalysis）运行。分析须自包含，不得依赖额外安装的包、网络访问或其它解释器。
