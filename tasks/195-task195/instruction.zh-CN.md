# 十二个已训练模型的有限预测评估

## 背景

比较所给验证记录上的有限预测误差。

输入包括留存的验证标签和十二份预测记录。

## 任务

使用输入中二十个真实公开验证帧与十二份已留存模型预测记录，独立计算每个模型在全部供给帧上的单帧能量误差与逐力分量误差，报告每个模型的力分量 RMSE 与每原子能量 MAE 及其精确分母（帧数与力分量数）。在两个合法指标中选择一个，用于两个共享同一 trial 的最终轮配对比较：trial 6061 与 trial 6062 的 random 减 adaptive，差值为正表示 adaptive 在该指标上更优。由计算出的差值推出每个比较的更优臂，并给出两 trial 合并后的方向结论。适用范围必须声明为恰为这十二个留存模型、这二十个真实记录帧及其分母，并排除 domain-100 与 multicomponent-49 集合——它们只有存量残差、没有独立预测记录。

## 要求

本题只考核对已记录预测的分析，不证明推理、拟合、选样或盲态控制的执行，也不做总体或泛化声明。

模型与帧顺序自由。对真实全帧、帧子集及记录顺序反转的输入重新计算，不能回显固定答案。报告解释指标选择、对比、方向与限制。

仅分析所给记录，无需新增模拟或模型推理。程序接受 `--inputs DIR --output DIR`，产物直接写入 DIR；对每份输入重新计算，包括任务规范描述的输入变化。使用内置 Python 依赖（标准库足够），无网络。

- 按所列输出约定 将所需结果和证据提交至 `/app/results/`。 可执行分析入口为 `/app/results/run/analyze.py`。
