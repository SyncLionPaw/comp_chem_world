# 任务：甲苯 ipso-BPR：双通道筛查与鞍点验证

## 背景

甲苯 ipso-双环过氧自由基（ipso-BPR）可经 C1 或 C2 通道开环。提供的资料包括 ipso-BPR 极小点的原生计算日志、BPR 与两个产物的几何、原始 DFT/F12 能量和位垒标量参考，以及给定资料 Supporting Information。资料不含已发表的鞍点坐标、Hessian、虚频、扫描点、搜索轨迹或保证收敛的初猜。请依据现有材料建立原子映射和初始结构。参考能量只用于比较，不能代替新计算或不确定度评估。

## 任务

在一次有界尝试中，用新计算筛查 C1 和 C2，并把至少一个通道作为潜在过渡态进行研究。依据实际筛查证据选择精修通道；说明为何停止另一通道以及仍有哪些未决问题。验证一个通道不能证明全局路径排序。

## 要求

- 环境：使用容器 `PATH` 上的 Python；所需科学计算包已预装。不要自行安装额外软件包，也不要通过网络获取依赖。

使用 HPC 时，见 `/app/AGENTS.md`：用 SSH 别名 `hpc`，远程工作目录使用唯一的 `~/submit-jobs/<task>-<utc>-<rand>/`，再核验科学结果。

先用所选引擎做短时试算，估计计算成本。每个通道至少计算三个不同几何的受限扫描点或路径点，并保留各自的原生能量或梯度结果。根据实际观察（例如拓扑、能量、收敛性和耗时）选择至少一个通道，执行新的开壳层 DFT 鞍点优化和完整振动分析。对该鞍点，沿其真实虚频的正负方向位移，或从该鞍点启动 IRC，证明两端分别弛豫至目标 BPR 与所选产物。两端均须在相同最终 DFT 水平优化并分析。单独优化提供的端点几何不能证明鞍点与两端相连。

用经验证的 BPR 和鞍点输出计算新同水平 DFT+ZPE 位垒，并与原始 DFT+ZPE 及已发表的高水平参考比较。任何转移修正须单独列出并作为有条件的估计，说明依据和局限。说明新计算支持什么、其不确定度以及不能证明什么；讨论原子映射与反应坐标、方法选择、虚频解释、失败或放弃的计算、停止决定，以及至少一种未采用但合理的坐标或方法。若没有验证成功的鞍点，应如实报告为未完成。

整个尝试限于 8 小时活动墙钟时间。失败、重试、取消及终止的分配均计入尝试期限。只有原始记录证明某段排队期间没有运行作业时，才可从活动时间扣除；重叠排队区间只计一次。没有此类记录的等待时间计入期限。

使用 HPC 完成计算。保留原生计算文件、作业记录和实际资源用量。遵守集群当前提交策略；分别报告请求资源和实测资源，不得用请求值或零替代缺失测量。

使用具备鞍点优化、完整振动分析和端点弛豫能力的原生开壳层 DFT 引擎。低成本方法可用于初猜或筛查，但不能替代最终 DFT 验证。须在试算期间冻结引擎版本、最终方法，以及将小虚频视为数值噪声的判定规则。保存原生输入、输出、几何、频率或 Hessian、真实连接轨迹、失败记录、命令、时间、退出状态及可取得的资源证据。可提供时报告自旋诊断。不得伪造缺失结果，也不得把失败计算称为有效筛查点。

### 输入与产物细则

输入位于 `/app/assets/`：Supporting Information、甲苯 ipso-BPR 原生日志、BPR/产物骨架几何、标量能量参考及其来源记录。

在 `final/` 下提供六项执行交付物：`ts_search_report.json`、`barriers.csv`、`native_outputs/`、`failures.md`、`resource_usage.csv` 和 `execution-receipt.json`；另提供用于参考与不确定度评估的 `references_uncertainty.md`。任何 F12 转移估计均须说明假设和局限。报告须覆盖两个通道、每个通道至少三个筛查记录，并说明精修或停止的理由；状态须区分 `validated`、`screened_unresolved` 与 `failed`。位垒表每个通道一行，未验证通道的新能量和位垒栏留空。`native_outputs/` 保存原生计算文件、几何及连接证据；同时保存失败记录和逐作业资源记录。公开机器可读合同在容器内挂载为 `/app/output-contract.json`，SSH/Slurm 接口说明位于 `/app/environment/README.md`；其中列有报告字段、原生文件绑定和收据结构。如实说明缺失的执行或资源证据，不得将 SSH 凭据写入提交文件。

见 `/app/AGENTS.md`，用 SSH 别名 `hpc` 操作 Slurm，并将所有 `.submit-job/*.json` 状态文件原样保存在 `final/native_outputs/slurm/`，包括失败和取消的作业。保留原始计算文件，并将科研阶段与对应作业 ID 关联。
