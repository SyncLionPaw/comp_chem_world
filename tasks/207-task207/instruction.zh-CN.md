# 覆盖率混杂下的方法公平排序

## 背景

不同有效结构集合会混淆电荷方法的吸附性能排序。

公开输入提供归档观测、归档模式及家族代理方法约定。

## 任务

利用归档观测比较各自有效集和共同域的方法排序、覆盖代价及家族敏感性。

## 要求

- 固定 Only Def2 atoms=1、PO Vol.>0。Valid 表 ok 定义有效性，保留 ko/nan 分母及未知失败原因。四种方法须比较 CO2 热及至少一种吸附量。报告结构权重和精确六位大写字母 CCDC refcode-root 家族代理，未匹配 ID 保留未识别。选择主 cohort、观测量、指标和权重并给出计算得到的排序变化。提供可运行 analysis.py，保留精确字段及未定义相关系数的空单元格。不重跑吸附模拟。
- 仅使用本题公开输入，保留全部必要状态、失败、单位及可复现证据。
- 在低权限环境中运行 `outputs/code/analysis.py --inputs /inputs --output /out`，仅使用提交代码和公开输入。

- 回放须在空目录生成规定的科学结果。

- 按所列输出约定提交规定产物。
