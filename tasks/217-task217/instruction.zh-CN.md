# EVB 反应区域拓扑与力场参数完整性

## 背景

解析四种嵌合体的 Q6 EVB 输入，核对反应区映射、参数覆盖和跨体系一致性。

存档提供坐标、协议和 EVB 输入。

## 任务

解析四种嵌合体的 Q6 EVB 输入，核对反应区映射、参数覆盖和跨体系一致性。

## 要求

- 解析四份 .fep、拓扑和51窗口输入。
- 识别全部17个 Q 原子：Asp 6、CSP 8、HOW 3。
- 引用类型均须有 atom_types/Lennard-Jones 定义；氢的零 LJ 合法。
- 核对 change_bonds 中 CSP.SGP–CSP.PO 断裂及 CSP.PO–HOW.OW 形成。
- 比较四体系原子类型、LJ、键合参数，允许 PDB 索引不同；接受两种沉积标签拼写。
- 使用 Python 标准库，无需 Q6 动力学。
- 科研数据仅使用已提供的输入。

- 提交的 JSON 对象成员名必须唯一，数值必须有限；产物路径可指向 `/app` 内的文件。
- 按所列输出约定提交规定产物。
