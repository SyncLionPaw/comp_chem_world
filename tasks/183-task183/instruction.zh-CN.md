# 任务：量化水的静态氢键网络与四面体有序度

## 背景

输入是两条历史非盲的 300 K 周期水轨迹，每条 201 帧、间隔 50 fs，含 64 个 O 和 128 个 H，晶胞为边长 12.4 Å 的立方体；类型 1 为 O，类型 2 为 H。本题不要求模拟、DFT、训练或推理。

输入与可用资源按下文说明；需要自行获取的资料仍由任务执行者获取。

## 任务

从几何重建 O–H 映射，并量化静态氢键网络和局部四面体有序度。

## 要求

- 环境：使用容器 `PATH` 上的 Python；所需科学计算包已预装。不要自行安装额外软件包，也不要通过网络获取依赖。

每帧按正交晶胞 MIC 将每个 H 指派给最近的 O。只有在所有最近 O–H 距离均 <1.25 Å、最近与次近距离差均 >0.20 Å，且每个 O 恰有两个 H 时才接受映射。报告所有帧的诊断；任一门槛失败即停止，不得猜测拓扑。

不同 O 原子间，若 r(O_d,O_a) < 3.5 Å 且 MIC 向量 O_d→H 与 O_d→O_a 的夹角 <30°，则记录有向 donor–H–acceptor 键。构图时将每对 O 去重为一条无向边，并逐帧报告度数直方图与连通分量大小。

对每帧每个 O，使用 MIC 向量，在最近的四个其他 O 上计算 q = 1 − (3/8) Σ_(j<k) (cos ψ_jk + 1/3)^2。第四近邻距离并列时按 O 原子 ID 升序裁决。保留负值；报告每个 O 的 q 值，以及逐帧 count、mean、总体标准差（ddof=0）、minimum、median 和 maximum。

### 输入与产物细则

输入为 environment/assets/public-inputs-v2/trajectory-manifest.json 列出的两条轨迹。提交 final/relabel/network-analysis.json，包含来源哈希、映射规则及逐帧诊断、有向键、无向图统计、逐 O q 值、逐帧 q 汇总和解释限制。这些是历史非盲轨迹上的静态分析，不能证明氢键寿命、体系平衡或实验一致性。完整输出字段与形状见公开输出格式：environment/assets/public-docs-v2/output-schema-v2.md。
