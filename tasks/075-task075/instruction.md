# Task: Asp50/Asp397 Dyad Proton-Exchange Barriers

## Background

Study proton exchange in the Asp50/Asp397 shared-proton dyad within a low-dielectric protein interior; the chemical question and model context are in `environment/assets/qm_task.md`. Use small-fragment models of two carboxylates (acetate or formate), both without a bridging water and with one bridging water; set the implicit-solvent dielectric constant to approximately 4. This model and the 3.0 kcal/mol classification threshold are for interpreting this task and are not universal physical laws.

## Task

Choose and explain the carboxylate, initial geometry, bridging-water position, and transition-state search method. For each model, locate two minima with the proton on opposite sides and one proton-transfer transition state; confirm stationary points by frequencies and calculate forward and reverse barriers from native electronic energies. Assess whether exchange is facile for each model; do not assume barrier values or conclusions. Report electronic barriers unless zero-point or thermal corrections were actually calculated. Do not claim an IRC-confirmed pathway unless IRC was run.

## Requirements

- Environment: use the container Python on `PATH`. Preinstalled packages include geomeTRIC, h5py, NetworkX, NumPy, PySCF, SciPy. Do not install additional packages or fetch dependencies from the network.

If using HPC computing resources, consult `hpc`.

- Every submitted minimum and transition state must have native CML/XML produced by an actual program (including XML format) and a matching optimized XYZ. Handwritten summaries, synthetic logs, or other files cannot substitute for native computational evidence. Each no-water model has composition acetate shared-proton model C4H7O4 or formate C2H3O4; the corresponding bridging-water models are C4H9O5 or C2H5O5, with a complete water molecule located between the two carboxylates. Native output must include optimized coordinates, Hartree electronic energy, all 3N−6 frequencies in cm⁻¹ and their mode displacements, optimization-completion and stationary-point evidence, program/units, atoms, total charge −1, spin multiplicity 1, method, basis, implicit solvent, and dielectric constant. Submit native output using this CML convention: one unique `cc:hfenergy` with numeric text and `units` containing `hartree`; `cc:frequency` and `cc:displacement` arrays; and scalar values `cc:program`, `cc:method`, `cc:basis`, `g:charge`, `g:mult`, `g:solvent`, and `g:eps`. Also include `g:optimization` text explicitly containing “optimization completed” and “stationary point found”; optionally include `g:gradientmax` (Hartree/bohr) and `g:stationarytype` (`minimum` or `transition_state`). These `dictRef` values must match exactly; XML namespace prefixes may differ, but CML elements must use the `http://www.xml-cml.org/schema` namespace. Text of `cc:hfenergy`, `cc:frequency`, and `cc:displacement` must respectively be one finite energy value, a complete space-separated frequency array, and a space-separated displacement array; there must be exactly one frequency-array node and one displacement-array node. Frequency and displacement text order must agree: for each mode, list all atoms' x,y,z displacements in sequence. Values for `cc:program`, `cc:method`, `cc:basis`, `g:charge`, `g:mult`, `g:solvent`, and `g:eps` may be in `dictRef` scalars on any descendant element. For each endpoint, JSON energy must agree with native energy within 2×10⁻⁵ Hartree, frequencies within 1 cm⁻¹, and the XYZ must be standard line format: atom count on the first line, a comment on the second, then element symbol and x, y, z (Å) on each line. Element order must match CML and coordinates must agree within 0.025 Å. If native output includes maximum gradient, minima must not exceed 4×10⁻⁴ and transition states 5×10⁻⁴ Hartree/bohr.
- The two minima must place the proton on opposite carboxylates and have no significant imaginary frequency below −20 cm⁻¹. The transition state must have exactly one frequency below −20 cm⁻¹; its native displacement must have an absolute normalized projection of at least 0.20 onto the specified O–H–O proton-transfer coordinate. Use 1-based indices in `transfer_atoms` to identify `oxygen_a`, `proton`, and `oxygen_b`. A minimum with a slight negative frequency (−20 to 0 cm⁻¹) requires manual review.
- For each model, report forward and reverse electronic barriers (kcal/mol), calculated as transition-state energy minus the corresponding minimum energy and converted with 627.509474 kcal mol⁻¹ Hartree⁻¹. The JSON values must agree with recomputation from native endpoints within 0.02 kcal/mol. The report must explain the model, method, TS frequency/mode projection, unit conversion, and limitations; do not overstate descriptive evidence beyond the model.
- Apply structured classification to the maximum bidirectional electronic barrier for each model: the threshold is fixed at 3.0 kcal/mol; values at or below it are `facile`, and values above it are `not_facile`. This is an operational interpretation for this task only. Automatic calibration applies only to acetate, B3LYP/6-31G(d), and dielectric 3.95–4.05; other methods/model routes require expert review and do not mean the calculation itself failed.
- Follow the host execution profile and task run budget. Complete both model calculations and analyses meeting the evidence requirements above. The total execution-time budget is 14,400 seconds; an unfinished calculation or missing deliverable does not count as completion.

Use direct proton transfer between the two nominated carboxylate oxygens, including in the explicit-water model. At the saddle, both O–H distances must be 0.65–1.55 Å and O–O must be at most 2.8 Å. At each minimum, the shorter O–H distance must be at most 1.25 Å, the longer at most 1.8 Å, and their difference at least 0.15 Å. For connectivity, use C–O <1.75 Å, acetate C–C <1.85 Å, and C–H or water O–H <1.25 Å. The intact water oxygen must be within 4.25 Å of both transfer oxygens.

### Input and deliverable details

Submit `barriers.json`, `structures/`, and `report.md` in `final/`. The top level of `barriers.json` is `{"schema":"case06-barriers/v1","models":[...]}` and must contain at least one no-water and one bridging-water model. Each model must contain a unique non-empty string `model_id`, Boolean `bridge_water`, `energy_unit`=`hartree`, `barrier_unit`=`kcal/mol`, integer `charge`=−1, integer `multiplicity`=1, non-empty strings `method` and `basis`, `solvent: {model,dielectric}` (`model` is one of `cpcm,cpcm-like,pcm,implicit`; dielectric 3.5–4.5), `transfer_atoms: {oxygen_a,proton,oxygen_b}` (three distinct 1-based integer indices), two `minima`, one `transition_state`, `barriers_kcal_mol: {forward,reverse}`, and `scientific_assessment`. Each endpoint contains finite `energy_hartree`, a finite `frequencies_cm-1` array (the underscore spelling `frequencies_cm_minus_1` is also accepted), and non-empty `native_output` and `geometry_xyz` path strings, resolved relative to the application root, e.g. `final/structures/...`. The two minima must locate the proton on opposite sides.

`scientific_assessment` contains `barrier_basis`=`electronic_energy`, `facile_threshold_kcal_mol`=3.0, `maximum_bidirectional_barrier_kcal_mol` recomputed from native endpoints, and `verdict`. Routes outside the calibration scope above require expert review even when evidence is complete; a minimum with slight negative frequencies (−20≤ν<0 cm⁻¹) also requires expert review. Check native gradients against the limits above only when the output provides them. Each model assessment must match `barriers.json`, including model order. Assessment must include non-empty `model_id` and `barrier_basis`, finite `facile_threshold_kcal_mol` and `maximum_bidirectional_barrier_kcal_mol`, and `verdict`. `final/native-run.log` may be included as supplementary evidence but cannot replace native endpoint output.
