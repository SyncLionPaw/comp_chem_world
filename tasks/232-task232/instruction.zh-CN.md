# 有限来源配对能量的自由能微扰校正

## 背景

近似势与其训练所用的第一性原理能量，在一组有限的配对构型上可能出现系统性偏差，而该偏差会传播到由这些构型构建的自由能估计中。给定记录给出立方相与四方相在 170 K 与 194 K 下各 50 个配对的 320 原子帧，并附每帧的原始第一性原理标准输出与对应的历史模型能量。

原始标准输出包含每帧的收敛能量、晶胞和坐标；历史模型能量作为给定输出提供。

## 任务

解析每份完整配对的原始标准输出，并在 1e-4 埃的打印舍入限制内保持帧、几何与来源身份一致。以整胞 eV 计算 delta = E_DFT - E_GAP。

评估标准的模型采样校正 -kBT * log(mean(exp(-delta/kBT)))，以 kB = 8.617333262145e-5 eV/K 稳定计算，并单独计算反号打印表达式诊断量。只有在指数平均之后才按原子归一化（乘 1000/320 得 meV/atom）。报告两个温度下的相间比较，即立方减四方校正。

在 2、5、10、25 中选择 `block_frames`，在 2..5 中选择 `stride`。

## 要求

- 保留标准与反号结果、全部 50 个有序前缀、全部 50 个逆序前缀、归一化重要性权重、ESS 与最大权重。
- 评估固定分块删除 5 与 10 加上你选定的块长，固定 stride 1、2、5 加上你选定的 stride。这些都不移除完整 50 帧基线。
- 报告两个温度下的相间比较，即立方减四方校正，以 meV/atom 计。
- 历史模型能量是给定输出，不是新推理，也不是作者原始预测。重要性 ESS 不是独立轨迹样本数；分块删除区间是描述量，不是已校准的置信区间。这些记录不建立无条件自由能收敛，不重建 PCA/PAMM/ITRE/TI，也不确定物理居里温度或 DFT/体积偏差的唯一解释。准确计算得到的负面重叠或敏感性结果同样完成任务。
- 整胞自由能算术 atol 1e-10 eV；meV/atom 与重要性权重/ESS atol 1e-8；给定与原始能量 atol 1e-9 eV/Ry；整数与完整分母要求精确。

按所列输出约定提交结果。

可用以下命令复现规定的结果：

```
python3 /app/public/replay.py --inputs /app/inputs --spec /app/public/example-spec.json --out /app/final
```
