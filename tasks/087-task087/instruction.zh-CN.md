# 红外光谱中的分子结构识别

## 背景

红外光谱能够约束分子结构，但其歧义取决于研究体系、光谱分辨率和比较方法。本题不预设科学数据集或模型，请自行选择适用的公开资料。

## 任务

围绕红外光谱识别分子结构，研究一个聚焦的问题。说明研究动机，自主选择体系与方法，给出实际结果所能支持的最强结论。

## 要求

- 在给定本地环境中开展研究，不提交远程作业。记录来源、已知许可和实际软件；许可无法确认时填写 `unknown`。
- 说明方法、观察、解释、不确定性、局限和结论。区分观察、推断、假设及待解决问题，将实质性主张与保留的证据关联。
- 保留理解和复现工作所需的数据、分析与执行记录。区分已完成计算与计划工作，不虚构活动，也不把记录完整等同于科学结论成立。

提交检查只覆盖证据完整性。科学结论须经独立复核。

## 文件

公开输入文件：

| 文件路径 | 说明 |
| --- | --- |
| — | 未预置科研数据。 |

提交 `/app/final/research-report.md`、`/app/final/research-manifest.json` 及支撑证据。

JSON 清单包含三项：

| 项目 | 内容 |
| --- | --- |
| `claims` | 每条含 `claim_id`、`claim_text`、`status`（`observed`、`inferred`、`unresolved`）和 `evidence_paths`。标识唯一，以字母或数字开头，仅含字母、数字、`.`、`_`、`-`，不超过 128 字符。观察及推断须引用证据；未解决主张可以不引用。 |
| `artifacts` | 报告及每个证据文件各有一条 `{ "path": "final/..." }`，不列清单自身。所有引用路径相对 `/app`，对应 `final/` 内已列出的常规文件，不使用链接。 |
| `reproducibility` | 含 `execution_status`（`not_run` 或 `executed`）、`execution_evidence_paths`、`commands`、`software`、`data_sources`（每条含 `description`、`license`）。已执行工作须引用保留的日志或输出，记录实际命令和软件；未执行工作证据路径为空，其他列表也可为空。 |
