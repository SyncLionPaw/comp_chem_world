# λ 分布与质子化布居

## 背景

在接近 pKa 的条件下，λ 分布应能分辨两个质子化端态。本题利用所给三肽体系、力场与校准参数，比较观测布居与理论参考。

输入包括三肽体系、力场、校准参数与理论比较数据。

## 任务

规划并完成 Asp、Glu、His 的规定单 pH 模拟，重建 λ 概率分布、识别端态峰，并比较轨迹平均去质子化坐标与 Henderson–Hasselbalch 预测。遵守下列集群和计算要求并保持给定科学模型，自主选择软件准备方式及作业组织。

## 要求

- 使用 `ikkem-slurm` 检查已配置集群，并在 Slurm分配的计算节点上执行全部规定生产模拟。本地仅用于准备、传输、监控、轻量检查及最终产物整理；连接或调度失败后不得以本地生产计算替代规定的集群计算。
- 准备支持给定 λ动力学模型的 GROMACS CpHMD fork，生产前完成启动检查；启动检查不能替代规定的生产采样。
- 集群探测须遵守已配置的连接等待设置。连接或调度无法恢复时，保留失败证据并报告执行受阻；不得伪造成功，也不得将启动后取消的生产作业记为完整计算。
- 保留提交脚本、科学命令与输入身份、作业 ID、原始调度回执、计算节点原生日志，以及作业与最终产物的对应关系。执行记录收集至 `/logs/agent/hpc-evidence/`，科学产物仍回收到原规定路径；调度正常退出本身不证明科学结果正确。
- Asp、Glu、His 分别使用 pH 4.0、4.5、6.5；每种体系完成一次 20 ns 生产模拟。
- 使用 GROMACS CpHMD fork 和给定体系参数，保持 λ 输出间隔及约束设置；记录并解释平衡段的处理。
- Asp/Glu 使用第二态坐标，His 使用两个中性态坐标之和。分布必须来自实际轨迹，覆盖全部分析值，不得通过改变分箱制造双峰。
- 报告分箱及归一化方式。概率质量与概率密度应按区间宽度正确转换；双峰需有两个端态峰、峰距大于 0.5、峰高比在 0.2 至 5 之间，中部低于两个端态峰。另按 [-0.2,1.2] 上 50 个等宽区间检查形状。
- 平均去质子化坐标与 HH 预测的差异不得超过 0.08。所有数值应有限，日志应证实完整生产运行及启用的 λ 动力学。
- 保留实际模拟输入、启动与分析命令、原生输出和可获得的调度回执，包括失败或中止的尝试。结果应来自完整生产记录，保留独立数值核验所需的有效参数和分析窗口。

- 按所列输出约定提交规定产物与运行证据，所有关联证据保存在提交目录内。
