# 周期电荷的有限求和收敛与表示不变性

## 背景

周期电荷求和可能依赖截断和晶胞表示。

公开输入提供原始观测、几何、参数及方法约定。

## 任务

检验 DOTSOV02 的 EQeq 求和收敛及等价晶胞、原点平移不变性。

## 要求

- 用有限数值作为 `summation_setting` 的扫描键，例如 1、2、3。同一表示的首行 `compared_to_setting` 留空，此后填写前一步的数值键。`R03-M03` 等描述性标签可放在 `run_id`。
- 保留解析 EQeq 核、硬度几何混合、K=14.4/1.67 eV Angstrom/e²、中性 G=0/tinfoil 约定、非零自镜像及实际电荷 Taylor 系数。H 使用 -2.0 和 13.598 eV。预声明停止规则并扫描至少三个递增范围。最终数值电荷目标 1e-6 e；最多 12 次运行、每方向范围 20、两倍复制。保留原子映射和可运行 analysis.py。
- 仅使用本题公开输入，保留全部必要状态、失败、单位及可复现证据。
- 主晶胞每步至少提高一个截断范围，两个范围都不得减小。提交的最后两步最大逐位点电荷差须 ≤1e-6 e，并通过独立参考核验。另提交一种非平凡等价表示即可，可使用非整数分数坐标原点平移或非单位晶胞变换。

- 将 analysis.py 及依赖提交至 outputs/code/，并支持在空目录重新生成科学结果。

- 对固定 DOTSOV02 CIF，按 atom-site 循环原始行顺序从 1 编号，156 个基准原子 ID 依次为 `site000001` 至 `site000156`。CIF 标签可能重复，不能作为稳定 ID。主表示使用这些精确 ID 和零晶格像；等价表示将每个原子映射到基准 ID 和整数晶格像。
- 受控重放时，`/submission` 和 `/inputs` 为只读；`/out`、`/tmp` 与私有 `/dev/shm` 可写。公开运行时及 `/dev/null`、`/dev/urandom` 可用；不提供 `/proc`、私有数据或宿主专有路径。请使用命令行给出的路径，不要依赖宿主文件系统布局。
- 每种表示的首个收敛行将 `compared_to_setting` 和 `max_delta_q_e` 均留空；之后各行与紧邻的前一设置比较。
- 按所列输出约定提交规定产物。
