# Machine Learning in Chemical Reaction Space

## Overview

This benchmark is based on the study "**Machine learning in chemical reaction space**" by Sina Stocker et al., published in *Nature Communications* (2020).

The study extends molecular machine learning into chemical reaction space using the Rad-6 molecular and reaction-energy databases. Molecular representations, reaction-network topology and learned reaction energies connect prediction accuracy to the construction of reduced reaction networks. The central question is how learning strategies must change when molecules participate in many interdependent reactions.

**Reference:** Sina Stocker et al., *Nature Communications*, 2020. DOI: [10.1038/s41467-020-19267-x](https://doi.org/10.1038/s41467-020-19267-x).
