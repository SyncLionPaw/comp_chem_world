# Activation Energy Mechanistic Modeling

## Overview

This benchmark is based on the study "**Machine learning meets mechanistic modelling for accurate prediction of experimental activation energies**" by Kjell Jorner et al., published in *Chemical Science* (2021).

The study investigates nucleophilic aromatic substitution reactions, focusing on the prediction of experimental activation energies. It combines quantum-chemical transition-state descriptors with machine learning to examine how mechanistic information improves prediction and transferability. The benchmark tests computational evidence, representation choices, predictive uncertainty, and independent mechanistic research.

**Reference:** Kjell Jorner et al., *Chemical Science*, 2021. DOI: [10.1039/d0sc04896h](https://doi.org/10.1039/d0sc04896h).

## Tasks

| Task | Description |
| --- | --- |
| Task 1 | Audit SNAr geometries, stationary points, thermochemistry, and native execution evidence. |
| Task 2 | Compare mechanistic descriptors and baselines for predicting experimental activation energies. |
| Task 3 | Assess representation choices and learning curves on a small reaction dataset. |
| Task 4 | Evaluate uncertainty calibration, applicability domains, and risk-based prediction filtering. |
| Task 5 | Assess blinded native ORCA evidence for competing pathways and evidence-quality failures. |
| Task 6 | Conduct open-ended research on experimental SNAr activation free energies. |
