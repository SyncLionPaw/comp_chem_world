# Silicon–Oxygen Active Learning

## Overview

This benchmark is based on the study "**Modelling atomic and nanoscale structure in the silicon–oxygen system through active machine learning**" by Linus C. Erhard et al., published in *Nature Communications* (2024).

The study investigates silicon–oxygen materials with an atomic-cluster-expansion potential developed through active learning from first-principles data. It spans crystalline phases, surfaces, disordered structures, and finite-temperature behaviour. The central question is how a single interatomic model can describe this chemical and structural diversity with assessable accuracy and transferability.

**Reference:** Linus C. Erhard et al., *Nature Communications*, 2024. DOI: [10.1038/s41467-024-45840-9](https://doi.org/10.1038/s41467-024-45840-9).
