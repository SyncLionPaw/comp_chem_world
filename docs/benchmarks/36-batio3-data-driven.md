# Data-Driven BaTiO3 Thermodynamics and Dielectric Response

## Overview

This benchmark is based on the study "**Thermodynamics and dielectric response of BaTiO3 by data-driven modeling**" by Lorenzo Gigli et al., published in *npj Computational Materials* (2022).

The study combines first-principles reference calculations with machine-learning models of energy and polarisation to investigate BaTiO3. Thermal sampling connects Ti off-centering, lattice distortion and phase behaviour to static and dynamic dielectric response. The central question is how microscopic structural fluctuations produce ferroelectric transitions and macroscopic polarisation.

**Reference:** Lorenzo Gigli et al., *npj Computational Materials*, 2022. DOI: [10.1038/s41524-022-00845-0](https://doi.org/10.1038/s41524-022-00845-0).

## Tasks

| Task | Description |
| --- | --- |
| Task 231 | Reconstruct polarisation branches and summarise finite polarisation records. |
| Task 232 | Compare paired QE/GAP energy profiles and evaluate residual corrections with blocked holdouts. |
| Task 233 | Analyse Ti off-centering in short NVT trajectories and assess order–disorder identifiability. |
| Task 234 | Calculate spatial dipole-correlation tensors and finite-record ordering contrasts. |
| Task 235 | Recompute paired-energy free-energy perturbation and assess importance-sampling support. |
| Task 236 | Derive dielectric response from dipole autocorrelation and compare oscillator fits. |
