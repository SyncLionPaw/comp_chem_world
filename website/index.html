Abstract

comp-chem-world evaluates agents on computational chemistry workflows—geometry and thermochemistry audits, MD diagnostics, ML potentials, spectroscopy, electrocatalysis, and related paper-derived problems—inside Harbor sandboxes with numeric verifiers.

The scored benchmark is 245 research tasks (001–245) indexed to 38 paper-linked benches: 195 local + 50 HPC. Local runs use shared base images; HPC tasks need a separate connectivity image. Place the single offline archive from AI4EC at shared/inputs.tar.zst, then uv run init.

The same layout is built to scale: add Harbor tasks under tasks/, restore the shared wheelhouse and asset-store with init, and run concurrent jobs via the local-a/local-b and hpc configs.

Pipeline

  1. Offline inputs

    Obtain inputs.tar.zst from AI4EC; place at shared/inputs.tar.zst (do not unpack by hand).

  2. Initialize

    uv run init restores wheels/assets, writes .env, and builds base images.

  3. Model

    Set ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL; override model in configs/agent.yaml or CLI.

  4. Harbor

    harbor run -c configs/local.yaml -c configs/agent.yaml; use local-a/local-b or hpc.yaml as needed.

Coverage

Reactions & kinetics

Activation energies, aromatic radical rearrangements, organic emitters, reaction-space ML.

Interfaces & electrocatalysis

CO2 reduction, double-layer charging, hydration forces.

ML potentials & sampling

Deep eutectic solvents, DeepVES, NewtonNet Hessians, metals MLPs, zeolite NNs.

Materials & transport

Carrier scattering, Li titanate, layered lattices, phonon superconductivity, BaTiO3.

Soft matter & biomolecules

Condensates, host–guest water, Hsp60, protein–drug refinement, constant-pH MD.

Spectra, solvents & workflows

IR elucidation, NEP IR/Raman, AutoSolvateWeb, ChemGraph, Ai2-Kit pipelines.
